# Course project web2 Mehdi Benallal (GameMatch)

- Made this readme with : https://readme.so/

## Description

A full-stack web application developed for the Web2 course, this project uses a MERN (MongoDB, Express, React, Node.js) stack to provide a working front-end and back-end linked to a MongoDB database. The website features a user authentication system with secure login and registration, and a personalized bookmarking feature that allows users to save their favorite games and removing them.
